Websites are structured collection of interlinked web pages coded mainly in HTML – Hosted On Servers
What Happens When You Visit a Website
Entering the URL--> Finding the Server (DNS - converts domain into Servers IP Address then locate) --> Sending a Request (HTTP/HTTPS) --> Server Processing --> Rendering the Page 
structure (HTML)
Visuals , Colors, layout Font (CSS)
JavaScript: Powers interactive features like pop-ups, forms, and live updates

Types of Website -
Static Website – HTML ,CSS Or Js and No Server Interaction – Fast Loading ,No DB 
Dynamic – Web Pages Generated at runtime using server-side scripting languages like PHP, Node.js - Pages built based on user requests, enabling real-time updates. Easier to update

Domain - A unique address on the Internet - www.example.com
Actual name – “example” that we search
Domain extension or top-level domain – “.com” indicates the type or purpose of the website.
Behind the scenes, the Internet's  Domain Name System (DNS) translates human-friendly domain names into IP addresses
